# Goo Journey / 粘球远行

An original three-level bridge-building game using RayGame and Box2D 2.4.2.
Build elastic triangles, carry little lights to a lantern, and rebuild when a
connection snaps. The brook, tower and windy pass have distinct layouts.

```sh
xmake f --physics_box2d=y --build_examples=y
xmake build goo_journey
xmake run goo_journey
xmake android --game=goo_journey
```

Click an empty spot near at least two balls, or drag from BUILD and release.
Dashed strands preview connections. Drag green balls to adjust the structure;
gold sockets remain fixed. RECYCLE removes a ball and returns it to the budget.
When the nest connects to either lantern socket, SEND THE LIGHTS starts travel.
Lights exert weight on the bridge; a severed occupied strand drops its travelers.
Rescue 5, 6 and 6 lights respectively within four minutes. Spare balls improve
the score. Progress, best scores, language, volume and display settings are saved.

Mouse and captured touch use the same controls. Keys: 1 build, 2/right-click/Space
toggle recycle, 3 send, 4 physics overlay, P/Escape/Android Back pause, R retry,
F11 fullscreen. Focus loss pauses and cancels dragging.

Desktop output: `bin/goo_journey.exe` (Windows). Final APK:
`bin/android/arm64-v8a/release/goo_journey.apk`. Intermediates remain under `build/`.
User data and `logs/game.log` use the platform's `raygame.goo_journey` user-data
directory. `--data <directory>` overrides it; `--smoke --data <absolute-directory>`
runs graphical regression checks with isolated saves and screenshots.

The scene owns a `Physics2DWorld`. Circles and elastic distance joints provide
structure; travelers follow the connection graph and distribute their weight
to the endpoints beneath them. Connections are rendered as elastic strips and
do not have separate rod collision fixtures. Placement rejects terrain crossings.
Sustained excess joint force/strain breaks a connection. This is a stylized game,
not a structural engineering simulator.

Code, vector artwork and procedural world art are original to this repository.
Audio is generated by `examples/common/generate-campaign-audio.py`. Font and
Box2D notices are included in assets. See `docs/PHYSICS2D.md` for the engine API.
