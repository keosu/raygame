# 泽塔传说 · Ultra Quest

> 非官方同人作品，仅供学习与交流，与圆谷制作无关。奥特曼泽塔、雷德王等角色版权属于原权利人；
> 战斗立绘裁剪自 Ultra 系列百科（ultra.fandom.com）的官方渲染图，人物与场景由代码绘制，
> 音效与音乐由脚本合成。若权利人提出要求，将移除本示例。

以 RayGame 制作的奥特曼动作冒险小样：先以人类形态在小镇调查，再变身奥特曼泽塔，与雷德王实时对战。

## 第一章　地底的咆哮

1. **调查**：STORAGE 队员夏川遥辉在城郊街区走访居民、查看现场，收集 3 条线索
   （温热的裂缝、汤碗的波纹、地底的吼声）。街区会周期性地震，工地入口在线索齐全前不能进入。
2. **变身**：雷德王从工地冲出地面，遥辉插入赛罗、赛文、雷欧三枚奖章变身奥特曼泽塔。
3. **战斗**：1 对 1 实时战斗，120 秒彩色计时器，胜利后进入结语和战斗评价（C ~ SS）。

## 战斗系统

| 操作 | 键盘 | 手柄 | 说明 |
| --- | --- | --- | --- |
| 移动 | A / D、← → | 左摇杆、十字键 | 自动面向怪兽 |
| 跳跃 | K / W / 空格 | A | 空中按攻击为飞踢 |
| 攻击 | J / Z | X | 刺拳 → 直拳 → 回旋踢三段连击，最后一段击退 |
| 防御 | L / S（按住） | LB / RB | 正面伤害减 80%；攻击到来前 0.16 秒内按下为完美防御 |
| 冲刺 | Shift / X | B | 0.2 秒无敌，可穿过冲撞 |
| 光线 | U / V | Y | 能量满时发射泽斯提姆光线（蓄力 0.55 秒，持续 1.3 秒，期间怪兽无法行动，冲撞除外） |

- **能量**：命中、击碎岩石、格挡和完美防御都会积攒能量，满格可用光线。
- **雷德王的四个招式**都有「！」预警和应对提示：
  - 重击：近身抡臂，可击倒。防御或后撤；完美防御会让它失衡。
  - 冲撞：霸体冲锋，可击倒。冲刺穿过或跳过；撞到场边大楼会眩晕。
  - 投石：抛出岩石。可以打碎岩石获得能量，或躲开。
  - 跺地：跳起落地，向两侧发出冲击波，无法格挡，只能跳起躲避。
- **破防**：短时间内累计伤害足够会让雷德王失衡。血量降到一半时咆哮进入狂暴：出招更快，投石变为三连，跺地变为两次。
- **彩色计时器**：剩余 40 秒或体力低于 30% 时变红闪烁，时间耗尽即失败。
- **取消**：攻击收招时可以用冲刺或防御取消。
- **评价**：综合剩余体力、用时、完美防御次数和最大连击。

## 运行与验证

```powershell
xmake build ultra_quest
xmake run ultra_quest
# 截图巡检（隐藏窗口，自动走完调查、变身、战斗、结算和失败流程）
build\desktop\windows\x64\release\ultra_quest.exe --capture build\uq-shots
# 机器人自动对战平衡报告（4 个水平 × 200 场）
build\desktop\windows\x64\release\ultra_quest.exe --balance build\uq-balance.txt
# Android
xmake android --game=ultra_quest
```

## 结构

| 文件 | 内容 |
| --- | --- |
| `Fight.h/.cpp` | 纯逻辑战斗模型：60 Hz 定步长、状态机、判定、飞行物、事件队列、评价；`FightBot` 自动对战 |
| `FightScene.*` | 战斗画面：镜头缩放、视差城市与可倒塌建筑、姿势立绘、特效、HUD、开场/结算/暂停 |
| `ExploreScene.*` | 调查街区、NPC、线索、地震与怪兽出现 |
| `TransformScene.*` | 变身过场与标题页 |
| `Story.*`、`assets/story/chapter1.txt` | 剧本格式与打字机对话框 |
| `Characters.*` | 代码绘制的人物与对话头像 |
| `Controls.*` | 键盘、手柄与触屏按键合并为同一组动作 |
| `Fx.*` | 火花、尘土、碎片、冲击环、浮动文字 |

## 素材工具

- `tools/make_poses.py`：从百科渲染图生成 `assets/poses/`，统一同一角色的尺寸、裁掉底座、
  校正偏色，并写出身体中心与朝向（`poses.txt`）。下载时要取原始 PNG（`?format=original`）。
- `tools/make_audio.py`：合成全部音效与三首配乐（需要 numpy、soundfile）。
- `tools/make_icon.py`：用泽塔头像合成窗口、Windows 和 Android 图标。
- `tools/make_font.py`：按源码和剧本里用到的字生成中文字体子集。修改文本后需要重新运行。
